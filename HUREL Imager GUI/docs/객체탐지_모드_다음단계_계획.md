### Step 1: 사람별 영상 공간 및 LM 데이터·SP 설정 (기반 작업)
**목표:** 한 명의 사람에 해당하는 픽셀만 잘라서, 그 영역으로 SP를 정하고 재구성에 쓸 LM 데이터를 준비한다.

| 작업 | 내용 | 참고 |
|------|------|------|
| 1-1 | Bounding box로 해당 사람의 RGB/Depth 픽셀 추출 | `TrackedPerson.BoundingBox`, RGB/Depth 이미지 소스 |
| 1-2 | 추출된 Depth ROI의 **median** 값을 선원 위치(SP)로 설정 | C++/API에 SP 파라미터가 있으면 전달 |
| 1-3 | **영상 재구성 설정 시간**에 해당하는 LM 데이터 로드 | 설정 창 위치 영상 탭의 “영상 재구성 설정 시간” 사용, `LahgiApi.GetListedListModeData(timeInMiliSecond)` 등 |
| 1-4 | 사람별 `PersonRadiationData` 생성·관리 (TrackId 기준) | 기존 `PersonRadiationData` 모델 활용 |

**산출물:**  
- 사람별 Bounding Box → RGB/Depth ROI  
- 사람별 SP (depth median 기반)  
- 사람별 사용 LM 데이터 (시간 기반 필터)

### Step 2: 사람별 CA/CC/Hybrid 재구성
**목표:** SP와 LM 데이터를 이용해 사람마다 CA, CC, Hybrid 영상을 만든다.

| 작업 | 내용 | 참고 |
|------|------|------|
| 2-1 | LahgiApi/네이티브 측 SP 지원 여부 확인 | **확인 완료:** `s2M = SP + M2D` 관계로 기존 `s2M` 인자에 SP 반영 가능 (네이티브 수정 불필요) |
| 2-2 | 사람별로 CA/CC 재구성 호출 (SP 전달) | **객체탐지용:** `LahgiApi.GetRadation2dImageCountForObjectDetection(count, s2M, ..., objectId, boxCenterX, boxCenterY)`. s2M = SourcePositionM + M2D. 누적은 C++ 내부 처리. |
| 2-3 | 사람별 Hybrid 영상 생성 (CA+CC 합성) | **구현 완료.** C++ `GetRadation2dImageCountForObjectDetection`가 Coded/Compton/Hybrid 세 종 반환. `RadiationImage` 기존 로직(`mHybridImage = mCodedImage.mul(mComptonImage)`) 재사용, 누적도 accCoded/accCompton/accHybrid 별도 유지 |
| 2-4 | `PersonRadiationData`에 Current/누적 CA/CC/Hybrid 표시용 저장 | **3-4 구현 시 함께 구현.** 현재는 표시 시 API 호출 후 결과를 바로 CodedImgRGB/ComptonImgRGB/HybridImgRGB에 반영. 프로퍼티만 정의됨 |

**2-1 확인 결과 (SP 반영 방법)**  
- **RadiationImage.cpp:** `SP = S2M - M2D` (Source to Mask 거리) → **s2M = SP + M2D**.  
- 객체탐지 SP(Depth ROI median, m)를 선원–마스크 거리로 쓰면: **s2M = SourcePositionM + M2D** 로 기존 API 그대로 사용 가능.  
- **결론:** 객체탐지 경로는 `GetRadation2dImageCountForObjectDetection(..., s2M: SourcePositionM + M2D, ..., objectId, boxCenterX, boxCenterY)` 호출. boxCenter는 **848×480(RGB 이미지와 동일)** 픽셀 좌표.

**산출물:**  
- 사람(TrackId)별 Current CA, CC, Hybrid 영상

### Step 3: 재구성 영상 → RGB UV 변환 및 정합
**목표:** 재구성된 방사선 영상을 RGB 이미지의 UV(픽셀) 좌표에 맞춘다.

| 작업 | 내용 | 참고 |
|------|------|------|
| 3-1 | 재구성 영상 좌표계 → RGB 카메라 UV 좌표 변환 | **C++ 구현 완료.** `RadiationImage.cpp` YOLO 생성자: `GetCameraIntrinsics(fx,fy,cx,cy)`, T265_TO_LAHGI_OFFSET로 카메라·재구성 평면 관계 계산, RGB 픽셀 (u,v) → 3D 레이 → 평면 교차 → 재구성 픽셀 (col_recon, row_recon) 연속 좌표 |
| 3-2 | 방사선 영상 리샘플링(보간) | **C++ 구현 완료.** `cv::remap(reconImg, mCodedImage, map_x, map_y, INTER_LINEAR, BORDER_CONSTANT)` — 연속 좌표 + 선형 보간. MATLAB `scatteredInterpolant(u_proj, v_proj, filteredCAimg, 'linear', 'none')`에 대응 |
| 3-3 | RGB 이미지와 방사선 영상 정합(표시) | **구현 완료.** 일반 재구성 모드와 동일: 방사선 영상을 RGB 위에 **겹쳐 표시**(오버레이). RealtimeRGB=bbox만 그린 RGB, CodedImgRGB/ComptonImgRGB/HybridImgRGB에 객체탐지용 누적 영상 설정 → 동일 뷰에서 Opacity로 겹쳐 표시 |
| 3-4 | `PersonRadiationData.ResampledCA/CC/Hybrid` 등에 저장 | **미구현.** 구현 시 2-4(Current/누적 CA/CC/Hybrid 표시용 저장)도 함께 반영 — API 반환값을 PersonRadiationData에 저장 |

**구현 상태 (C++)**  
- **위치:** `Image reconstruction/RadiationImage.cpp` — 6인자 생성자(YOLO MODE) 내, reconImg·comptonImg 생성 직후.
- **변환:** RGB (u_rgb, v_rgb) → 레이와 재구성 평면(z=imagePlaneZ) 교차 → (x_det, y_det) → 연속 (col_recon, row_recon) → `map_x`/`map_y`에 저장.
- **보간:** `INTER_LINEAR`(bilinear) = MATLAB 'linear', `BORDER_CONSTANT` = 'none'(경계 외 상수). 내부 파라미터 없으면 기존 FOV 크롭+리사이즈(848×480) 폴백.

**산출물:**  
- 사람별 “RGB UV 위에 올라가는” 방사선 영상 (재구성→RGB UV 변환 + 선형 보간 완료; 블렌딩은 Step 7 등에서)

### Step 4: 프레임 간 누적 및 Shift
**목표:** 이전 프레임까지의 방사선 영상을 “사람이 움직인 만큼” 옮긴 뒤, 현재 프레임 재구성 결과와 합친다.

| 작업 | 내용 | 참고 |
|------|------|------|
| 4-1 | 이전 프레임 Bounding Box 중심 vs 현재 중심으로 **이동 벡터** 계산 | **C++ 구현 완료.** `boxCenterX/Y`(848×480, RGB와 동일)로 전달, 내부에서 `shift = current - prev` 계산 |
| 4-2 | 이전 프레임 누적 영상(Cumulated CA/CC/Hybrid)을 이동 벡터만큼 **shift** | **C++ 구현 완료.** `cv::warpAffine`으로 시프트 후 가산 (CppWrapper.cpp) |
| 4-3 | Shift된 누적 영상 + 현재 프레임 재구성 영상 **합산** | **C++ 구현 완료.** per-object 480×848 CV_32S 누적 버퍼 유지, 반환 시 Jet 컬러맵 변환(출력 480×848) |
| 4-4 | 사람별 CA_count, CC_count 유지 (이벤트 수 기반 표시 규칙용) | 아래 Step 5와 연동 (미구현) |

**구현 상태 (C++)**  
- **출력 크기:** 480×848 (RGB 이미지와 동일 픽셀 수).  
- **API:** `GetRadation2dImageCountForObjectDetection(..., objectId, boxCenterX, boxCenterY)` — 호출 시마다 해당 objectId 누적 갱신 후 누적 Coded/Compton/Hybrid 비트맵(480×848) 반환.  
- **Clear:** `ClearObjectAccumulation(objectId)` (퇴장 시), `ClearAllObjectAccumulations()` (세션 종료 시). ViewModel에서 호출 연동 완료.

**산출물:**  
- 사람별 시간에 따른 누적 CA/CC/Hybrid (C++에서 유지·반환)  
- 사람별 CACount, CCCount (Step 5에서 활용 시 추가)

### Step 5: 이벤트 수에 따른 표시 규칙
**목표:** CA/CC 이벤트 수에 따라 어떤 영상을 화면에 보여줄지 결정한다.

| 조건 | 표시 영상 | 비고 |
|------|-----------|------|
| CC_count > 10 **및** CA_count > 200 | Hybrid 누적 영상 | `radShow = mat2gray(radImagCumulation_HY)`, cutoff 0.85 |
| CC_count >= 5 | CC 누적 영상 | cutoff 0.75 |
| 그 외 | RGB만 (방사선 영상 없음) | `continue` 등 |

| 작업 | 내용 |
|------|------|
| 5-1 | 사람별 CACount, CCCount 반영 (재구성/누적 시 카운트 증가) |
| 5-2 | 위 규칙에 따라 “현재 표시할 영상” 선택 로직 구현 |
| 5-3 | 선택된 사람(또는 criminal 1/2)에 대해 해당 영상을 GUI에 표출 |

### Step 6: 테이블 선택 및 Criminal 판정

| 작업 | 내용 | 참고 |
|------|------|------|
| 6-1 | 테이블 체크박스(IsSelected) ↔ “해당 사람 방사선 영상 표시” 연동 | PersonTableItems.IsSelected |
| 6-2 | Criminal 판정 로직 구현 (caleMaxpos 등, MATLAB 로직 이식) | 소지자 의심/판단 → Source carrier O/X |
| 6-3 | 선택된 사람 없을 때: Criminal 1 또는 2로 판단된 사람 자동 표시 | Source carrier O/X 갱신 |
| 6-4 | 테이블 “Source carrier” 컬럼을 O/X로 갱신 | PersonTableItem.SourceCarrier |

**산출물:**  
- 체크 시 해당 TrackId 방사선 영상만 표시  
- 미선택 시 criminal 판정된 사람 영상 표시  
- 테이블에 O/X 반영
